# 注释规范（面向交付）

**状态**：词法规则已做成门禁（`scripts/checks/check-comment-style.sh`）；
长度与结构规则是 review 规则（见文末说明）。

源码注释是**交付物的一部分**：它面向的是「半年后接手的人」，而不是
「写这段代码时的自己」。本仓库的注释此前偏重开发过程（「本轮踩到了…」
「旧系统是…」），这类内容在开发过程记录里是有价值的史料，
放在源码里只增加噪声。

---

## 保留什么

| 类别 | 例子 |
|---|---|
| **非显然的「为什么」** | 为什么读列名而不是下标；为什么 `updated_at` 要刷新 |
| **契约与安全约束** | `is_folder` 必须是 0/1；文件名必须落在目录内 |
| **不变量** | 「过载时降频，绝不丢观测」；`dropped` 必须恒为 0 |
| **外部系统的怪癖** | macOS 权限不足时返回全黑帧而不是报错 |
| **口径来源** | 字段映射自旧实现哪一处（一句话，不展开对比） |

## 删除什么

| 类别 | 反例 |
|---|---|
| **复述代码** | `// 遍历所有活动`（函数名已经说了） |
| **开发过程叙事** | 「本轮踩到了」「第一版犯过的错」「当初我们…」 |
| **对旧实现的情绪化评价** | 「旧系统这么写简直离谱」 |
| **过期计划引用** | 「Phase 5 会改」（已经实现了） |
| **与本文件无关的背景** | 大段产品需求原文（放规划文档） |

## 位置与长度

- **模块级（`//!`）**：说清「这个模块负责什么、关键约束是什么」。
  目标 ≤ 6 行；超过 10 行通常意味着有一部分内容该搬到 `docs/`。
- **函数/类型级（`///`）**：只说调用方**无法从签名看出**的东西（口径、
  边界、失败语义）。目标 ≤ 3 行。公开 API 可以有更长的契约说明。
- **行内（`//`）**：解释「为什么这样写」，不解释「在做什么」。
- **不要**在注释里写变更日志（git 已经在做这件事）。

## 门禁能拦什么

`scripts/checks/check-comment-style.sh` 拦两类东西：

**一、过程叙事词汇**（不可能有技术含义的词）：
`踩到` / `第一版` / `我们之前` / `TODO(临时)`。
刻意不收 `本轮`、`这次`：在采集环里它们指「本次轮询」，是领域词汇，
拦它只会制造假阳性，进而让人学会忽略这条门禁。

**二、模块注释长度棘轮**：`//!` 块超过 `10` 行的文件必须列在
`scripts/comment-length-allow.txt`（每行一个路径，可写行尾注释）。
规则有三条：

| 情况 | 结果 |
|---|---|
| 超限且不在名单里 | **失败**（新写的长模块注释进不来） |
| 在名单里、且确实超限 | 通过（表示「待收敛」，数量只减不增） |
| 在名单里、但已经 ≤ 10 行 | **失败**（陈旧条目必须删掉） |

**三、函数注释长度棘轮**：`///` 块**直接贴在函数上**、且超过 `8` 行的，
必须列在 `scripts/function-doc-allow.txt`，格式是
`<路径>::<函数名>  # 为什么必须这么长`：

- 上限 8 行不是目标值（规范里的目标是 ≤ 3 行）—— 公开 API 的契约说明
  可以长，但**必须说明理由**：长注释不是错，没理由的长注释才是；
- **缺理由的条目会被拒绝**（`#` 后面必须写东西）；
- 收敛到 ≤ 8 行之后，条目要删掉，否则判为陈旧。

为什么函数注释用「登记 + 理由」而不是硬压：现有 7–8 行的函数注释有
10 处，全都是契约（口径、失败语义、安全约束）；机械压到 3 行只会把
契约删掉。棘轮保证的是「不再变长」，理由栏保证的是「长要有代价」。

为什么不做成「模块注释 ≤ 6 行」的一刀切：最省事的通过方式是把契约说明
删掉 —— 那比注释长一点更糟。棘轮只保证**不再变长、逐步变短**，
删减哪几行仍然要人判断。

  | 叙述动词开头（`// 遍历…`/`// 返回…`） | 10 | 逐条看过：实际写的都是「为什么」（例：「返回 200 + applied:false，让前端提示而不是让它以为修正丢了」） |

- **为什么这条不进门禁**：可用的词法标记都有正当的技术用法 ——
  `在此之前` 在阶段重放里指「处理这一步之前先 tick」，`从未` 在
  `state.rs` 里是「从未执行过时为 None」的字段语义。加进去只会制造假阳性，
  而假阳性会让人学会忽略门禁（见上文对 `本轮`/`这次` 的同类判断）。
  结论：行内注释靠 review，**证据是这张表**，不是一句「已经清理过了」。
